# Security

## Source Code

The BunkVerse source code is proprietary and is not included in this repository.

This repository contains documentation, screenshots, and other public project information only.

---

## Sensitive Information

The following should never be committed to this repository:

- Application signing keys
- Keystore files
- API keys
- Access tokens
- Passwords
- Private credentials
- Production databases
- Private configuration files
- Other confidential development resources

---

## Reporting a Security Issue

If you discover a security issue related to BunkVerse, please contact the developer privately rather than publicly disclosing sensitive information.

**Developer:** Amogh V P

For security-related communication, please use a private communication channel rather than opening a public issue containing sensitive information.
