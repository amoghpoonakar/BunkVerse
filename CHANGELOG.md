## Version 1.6 — Build 6

**Current Release**

### Core Features

- Introduced the Bunk Bank system
- Available Bunks tracking
- Bunk Pass for carrying unused bunks into future months
- Bunk Loan for borrowing bunks from future months
- Medical Leave support
- Undo support for recent Bunk Bank operations
- Monthly Ledger Reset

### Attendance Management

- Calendar-based attendance tracking
- Full Day Present marking
- Absent marking
- Partial attendance by subject
- Date-range attendance selection
- Holiday handling
- Sunday handling
- Examination day handling
- Cancelled class support
- Extra class support

### Timetable

- Flexible weekly timetable management
- Automatic class timing calculation
- Configurable lunch breaks for individual days
- Subject short codes
- Weekday timetable copying
- Custom Saturday schedules
- Half-day Saturday support
- Weekend class attendance

### Reports & Analytics

- Semester attendance reports
- Monthly attendance reports
- Custom date-range reports
- All-subject attendance reports
- Individual subject reports
- Visual attendance status indicators

### Data & Storage

- Local-first data storage
- Room / SQLite database
- CSV data backup
- `BunkVerse_Backup.csv` export
- Complete application reset

### Application Experience

- Built-in Markdown-based tutorial
- WebView-based tutorial rendering
- Lottie animations
- Material Components UI
- Futuristic dark HUD-inspired interface
- Google AdMob integration
